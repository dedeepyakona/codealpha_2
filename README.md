🚀 StylAI – Body Shape & Outfit Recommendation Chatbot

StylAI is an AI-powered fashion assistant chatbot that detects body shape and recommends outfits based on user preferences. It is built using Flask and deployed on Railway.

🧠 Problem Statement

The goal of this task is to design and develop an AI-powered chatbot capable of interacting with users in real time on a website. The chatbot should be able to understand user queries, provide instant responses, and improve user experience through seamless integration with the web interface.

🎯 Objective

To build a functional chatbot system that:

Responds instantly to user queries
Uses predefined patterns for understanding inputs
Integrates smoothly with a website interface
Enhances user engagement through conversational interaction
Ensures accuracy and reliability in responses

💡 Approach

The chatbot is designed using a retrieval-based model, where user inputs are matched with predefined patterns and mapped to appropriate responses. This ensures fast and consistent replies without requiring heavy computational resources.

🛠️ Technologies Used
Python 🐍
Flask 🌐
JSON (Intent & Pattern Matching)
HTML, CSS, JavaScript 🎨
Gunicorn 🚀
Render (Deployment ☁️)
